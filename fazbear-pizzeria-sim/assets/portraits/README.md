# Portrait sources

These art files were extracted from the user's own installed game files for use in this local mashup prototype:

- `freddy.png`, `springtrap.png`, and `nightmare-chica.png`: Ultimate Custom Night custom-night character portraits.
- `toy-bonnie.png`: Five Nights at Freddy's 2 custom-night portrait.
- `scrap-baby.png`: a crop of Scrap Baby from the Pizzeria Simulator intro scene; that game has no custom-night roster portrait.

The portrait images remain copyrighted game assets and should not be redistributed as a standalone asset pack.

- `bonnie.png`: locally drawn prototype portrait for Bonnie. The installed FNAF 1 executable exposed only the Freddy game icon, so a separate Bonnie portrait was not available in the extracted local files.
