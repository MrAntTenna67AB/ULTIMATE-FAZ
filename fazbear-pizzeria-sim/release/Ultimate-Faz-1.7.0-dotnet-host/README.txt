ULTIMATE FAZ 1.7.0 — Windows x64

Run Launch Ultimate Faz.cmd. It starts the game DLL through Microsoft's signed .NET 8 host. The folder includes the runtime, game data, artwork and audio. Steam's default install is detected automatically. No separate .NET installation is required.

The app executable is a DLL rather than an unsigned apphost EXE so the launch uses the signed Microsoft dotnet.exe.
